# SiMed-SSO
Данный проект включает в себя SSO сервис готовый к интеграции в различные системы, как СИМЕД, так и использующих их платформу систем. На стороне СИМЕД включает в себя админ панель для управления пользователями CRUD операции, а также API для взаимодействия по OAuth2.
## СТЕК
- Dotnet 10 на базе C#  
- Code first БД, entity framework
- Razor pages, ASP.NET Core
- Mailkit SMTP (mail.ru)
- Redis, Minio S3, PostgreSQL
